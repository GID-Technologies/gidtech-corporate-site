# GID Technologies Corporate Website

Premium dark-themed Next.js + Tailwind CSS website for GID Technologies.

## What is included

- Next.js App Router setup
- Tailwind CSS styling
- Responsive single-page corporate website
- Hero, credibility bar, what we do, StatBet proof, GidAds, ecosystem roadmap, process, principles, contact CTA, and footer
- Premium dark theme with glassmorphism cards, grid patterns, cyan accents, subtle animation, and status badges
- No public pricing and no exaggerated claims

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Edit content

Main content is in:

```bash
app/page.tsx
```

Global styling is in:

```bash
app/globals.css
```

Tailwind theme tokens are in:

```bash
tailwind.config.ts
```

## Deployment

This project is ready for Vercel deployment. Push to GitHub and import the repository into Vercel.
